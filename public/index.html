Quilon

A statically-typed, symbol-based language that compiles to native and should make me laugh.

Colorless deferred I/O on cooperative fibers — ordinary typed values, waiting when used. The runtime is still growing.

Custom rendering

Define how a record renders once; interpolation and output use it everywhere. 

<< core.io

User = {
  name :: Text,
  ` = () -> Text => < "@`it.name`" >
}

^ = () -> $ => <
  ada = User { name = "ada" }
  io.print("hello, `ada`")   ~ hello, @ada
  io.print(ada)             ~ @ada
>

Closures

Return a function that remembers its discount. Each closure captures its own value—no mutable state needed.

<< core.io

discount = (off :: Num) -> (Num) -> Num => <
  (price) => price - off
>

^ = () -> $ => <
  sale = discount(20)
  member = discount(10)
  io.print(sale(100))     ~ 80
  io.print(member(100))   ~ 90
  io.print(sale(100))     ~ still 80
>

Set algebra

Intersection finds common ground. Union and difference settle the rest—without changing either set.

<< core.io

^ = () -> $ => <
  ~ this is how you create a set
  ada = [|"mushrooms", "olives"|]
  lin = [|"olives", "peppers"|]

  shared = ada +- lin
  menu = ada + lin
  onlyAda = ada - lin

  io.print(shared.has("olives"))   ~ True
  io.print(menu.size)              ~ 3
  io.print(onlyAda.has("mushrooms")) ~ True
>

Sum types

A sum type carries its data and its own rendering; the match covers every possible state.

<< core.io

Parcel = Queued / Moving(Text) / Delivered {
  ` = () -> Text => <
    it ?
      | Queued => "packing your things"
      | Moving(city) => "next stop: `city`"
      | Delivered => "check the doorstep"
  >
}

^ = () -> $ => <
  parcel = Moving("Oslo")
  io.print("order: `parcel`")
  ~ order: next stop: Oslo
>

Operator overloading

Give a record equality and a hash with == and %; sets recognize equivalent values.

<< core.io

Point = {
  x :: Num, y :: Num,
  == = (p :: Point) -> Bool => <
    it.x == p.x && it.y == p.y
  >,
  % = () -> Num => < it.x * 31 + it.y >
}

^ = () -> $ => <
  a = Point { x = 3, y = 4 }
  b = Point { x = 3, y = 4 }
  visited = [|a, b|]
  io.print(visited.size)   ~ 1
>

Deferred I/O

The read starts immediately. Its ordinary Text value waits when compared—no async function signature.

<< core.io

greet = (name :: Text) -> $ => <
  name == "" ?
    io.print("hello, stranger") :
    io.print("hello, `name`")
>

^ = () -> $ => <
  name = @readStdin()
  io.print("What should I call you?")
  greet(name)
  ~ Type Ada, press Enter: hello, Ada
>

Tests

quilon test runs the checks beside your code; production builds leave those test blocks out.

<< core.io
<< core.test

shipping = (total :: Num) -> Num => <
  total >= 50 ? 0 : 5
>

test.describe("shipping", () => <
  test.it("below the threshold", () => <
    expect(shipping(49), equals(5))
  >)
  test.it("free from fifty", () => <
    expect(shipping(50), equals(0))
  >)
>)

^ = () -> $ => <
  io.print(shipping(50))   ~ 0
>
